It reduces the purchasing power of money. Economists commonly measure consumer price inflation using a consumer price index (CPI)."; } if (q.includes("supply") || q.includes("demand")) { return "Demand represents the quantities consumers are willing and able to buy at different prices. Supply represents the quantities producers are willing and able to sell. Their interaction determines market equilibrium in the basic competitive-market model."; } if (q.includes("elasticity")) { return "Price elasticity of demand measures how responsive quantity demanded is to a change in price. The basic formula is percentage change in quantity demanded divided by percentage change in price. A magnitude greater than 1 is generally described as elastic."; } if (q.includes("gdp") || q.includes("gross domestic product")) { return "Gross Domestic Product (GDP) measures the market value of final goods and services produced within a country during a given period. The expenditure approach is GDP = C + I + G + (X - M), where C is consumption, I is investment, G is government spending, X is exports, and M is imports."; } if (q.includes("microeconomics")) { return "Microeconomics studies the decisions of individual economic agents, including households and firms, and how they interact in markets. My current prototype knowledge base covers foundational concepts such as opportunity cost, supply and demand, elasticity, GDP, inflation, and the three main economic perspectives. A more advanced ÉcoBot will use an AI model to answer broader questions, work through exercises, and explain concepts step by step."; } function sendMessage(question) { const cleanQuestion = question.trim(); if (!cleanQuestion) return; addMessage(cleanQuestion, "user"); const answer = getEconomicsAnswer(cleanQuestion); setTimeout(() => { addMessage(answer, "bot"); }, 350); } form.addEventListener("submit", (event) => { event.preventDefault(); sendMessage(input.value); input.value = ""; }); suggestions.forEach(button => { button.addEventListener("click", () => { openChat(); sendMessage(button.dataset.question); }); }); });
